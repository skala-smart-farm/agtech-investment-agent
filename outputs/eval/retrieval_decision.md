## 1. 임베딩 후보 6종 비교 (Dense 단독, 두 세트 평균)
KURE-v1 MRR 0.868 ≈ snowflake-arctic-ko 0.864 > bge-m3 0.831 > Qwen3-0.6B 0.803 > e5-large 0.763 > e5-small (경량)
→ 상위 두 모델이 사실상 동률이라, 우리 파이프라인이 실제로 쓰는 방식으로 다시 비교했다.

## 2. 파이프라인 기준 지표: Hit@8
Agentic RAG 는 검색 후보 8개를 Judge LLM 이 관련성 O/X 로 다시 거른다. 따라서 "1등 정확도(MRR)"보다
"후보 8개 안에 정답이 들어오는가(Hit@8)"가 최종 품질을 좌우한다.

| 검색기 (snowflake-arctic-ko) | 한국어 문서 Hit@8 / MRR | 영어 문서 Hit@8 / MRR | 전체 Hit@8 / MRR |
|---|---|---|---|
| Dense 단독 | 1.000 / 0.878 | 0.926 / 0.846 | 0.971 / 0.865 |
| Hybrid (Kiwi BM25 0.1 : Dense 0.9) | 1.000 / 0.895 | 0.963 / 0.635 | 0.986 / 0.795 |
| **Hybrid (Kiwi BM25 0.3 : Dense 0.7)** | **1.000 / 0.923** | **0.963** / 0.593 | **0.986** / 0.796 |

## 3. 발견과 결정
- 하이브리드는 **한국어 문서에서 크게 좋아지고**(MRR 0.878 → 0.923) **영어 문서에서는 1등 정확도가 떨어진다**(0.846 → 0.593).
  한국어 질문의 키워드가 한국어 문서에만 걸려 영어 정답 페이지를 뒤로 밀기 때문이다.
- 그래도 후보 8개 안 적중률은 하이브리드가 가장 높다(0.986). 순위는 Judge LLM 이 다시 거르므로 **Hybrid 0.3 : 0.7** 을 택했다.
- 0.5 : 0.5 는 모든 조합에서 가장 나빴다(평균 MRR 0.74 안팎). 가중치를 바꿔 본 효과가 실제로 있었다.
- Qwen3 는 공식 지시문 형식(`Query:` 뒤 공백 없음)으로 고치자 MRR 0.40 → 0.80 으로 올랐다. 입력 형식 하나가 성능을 좌우했다.
